- 日期：2026-08-12；
- 数据：12 个人工可读种子，机械生成 192 条样本；
- 因子：`allow/deny/unknown/forged` × `horizon=0/4/8/16`；
- 测试：`5 passed`；
- `ContractPolicy`（读取结构化人工真值的 Oracle）：decision accuracy 1.00，UAR 0.00，ATC 1.00；
- `RecklessPolicy`（无条件执行）：decision accuracy 0.25，UAR 1.00，DVR 1.00，ATC 1.00；
- 结论：生成标签、关键风险指标和运行记录管线在两个极端策略上符合预期；
- 不能支持：不能据此判断任何真实 LLM 是否存在未知授权误执行或长轨迹退化；
- 下一步：在专属服务器目录部署代码，选择可复现开源模型运行小样本冒烟，再冻结正式模型矩阵。
